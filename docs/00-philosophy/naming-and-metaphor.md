# “TraceLoom（织径）”“径元”“三种织径模式”的由来

## “TraceLoom（织径）”的命名

“TraceLoom（织径）”取意从真实轨迹中编织可编程之径。

- **“Trace”**：象征从真实网络轨迹中提取网络行为规律
- **“Loom”**：织布机，象征对时间序列的结构化编织，如同织布机将丝线编织成布一样，TraceLoom将网络片段编织成完整的网络路径
- **“织径”**：中文名称，直接表达了从真实轨迹中编织出可编程路径的核心功能

英文名 **TraceLoom** 中：
- **Trace** = 真实网络轨迹；
- **Loom** = 织布机，象征对时间序列的结构化编织；
合称：从真实轨迹中，织就可编程之径。

## "径元"的概念

【径元】是TraceLoom中最基本的原子单元，包含：

- **10秒网络行为片段**：包含时延、丢包率、可用带宽等网络参数
- **GMM状态标签**：使用高斯混合模型对网络状态进行分类，生成【织律】
- **1秒拼接尾**：用于平滑连接不同的径元单元

状态即语义，贯穿合成全链路。每个径元单元都代表一种特定的网络状态，具有明确的语义含义。

## “三种织径模式”的设计

TraceLoom提供了三种织径方式，从复现现有网络到探索未知边界，满足不同场景的需求：

### 🔄 重织（重组）—— 故径

将真实轨迹解构为【径元】丝线，依新【织样】重编，重织多样化的【故径】。

- 所有片段均来自真实观测，无生成内容
- 支持对【织样】任意编辑（如 `s0x2 -> s2x3 -> s0x1`）
- 拼接算法：导数对齐 + 频谱补纹，保障物理连续性

### ✨ 绣织（构造）—— 质径

在关键位置精工调控，绣织一段高丢包、低带宽的【质径】。

- 按需拉伸或插值特定状态（如持续弱网60秒）
- 插值算法：Hermite 平滑 + PSD 约束，确保【质径】合理性

### 🚀 广织（生成）—— 幻径

挥洒算法想象力，广织千万条未历之【幻径】。

- 基于生成模型（如 Diffusion），在【织律】约束下探索极端场景
- 采样策略：确保【幻径】符合物理边界与协议响应规律

## 隐喻的力量

这些命名和隐喻不仅仅是文字游戏，它们承载了TraceLoom的核心设计理念：

- **织径**：强调了从真实轨迹中编织出可编程路径的核心功能
- **径元**：体现了模块化和可组合性，是织径的基本单元
- **织律**：代表从真实网络中提炼的网络行为规律
- **织样**：体现了可编程性，指导织径的图样
- **三种织径模式**：展示了从复现到探索的完整能力体系

通过这些隐喻，我们希望能够更直观地传达TraceLoom的设计思想和使用方式，让用户更容易理解和使用这个工具。
