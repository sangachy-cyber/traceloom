# Playback 底座设计约束

## 底座定位

Playback底座是织虚的唯一真实来源，所有生成的网络轨迹都基于此底座。它提供了高保真的网络数据，是织虚能够生成真实可信轨迹的基础。

## 设计约束

### 1. 数据源约束

- **长期回放**：HoloWAN Playback 长期回放数据
- **多地域覆盖**：必须覆盖不同地理位置的网络环境
- **多场景覆盖**：必须包含各种网络场景，尤其是典型弱网场景（如"西岑公寓"）
- **持续更新**：数据源必须定期更新，以反映网络环境的变化

### 2. 数据质量约束

- **高精度**：数据精度必须达到100ms级
- **高保真**：必须保留原始网络的所有特性，包括微观抖动、突发劣化、队列动力学
- **完整性**：数据必须完整，无缺失值或明显的异常值
- **一致性**：数据格式和采样率必须一致

### 3. 数据格式约束

- **三元组格式**：必须包含时延、丢包率、可用带宽三个核心参数
- **时间戳**：每个数据点必须包含准确的时间戳
- **结构化存储**：数据必须以结构化格式存储，便于后续处理和分析

### 4. 设计原则

- **不做转换**：直接使用原始数据，不进行任何可能引入失真的转换
- **直接回放**：从采集到仿真，语义零失真
- **透明性**：数据源和采集方法必须透明，便于验证和审计
- **可重现性**：基于相同数据源生成的轨迹必须具有可重现性

## 数据特性

### 微观抖动

网络延迟不是恒定的，而是存在微小的波动，这种波动称为微观抖动。Playback底座必须保留这种微观抖动，因为它对实时应用（如视频通话、在线游戏）的QoE有重要影响。

### 突发劣化

网络质量可能会突然恶化，如出现突发丢包或延迟激增。Playback底座必须捕捉这种突发劣化，因为它是导致网络应用性能下降的重要原因。

### 队列动力学

网络中的数据包会在路由器和交换机的队列中排队，队列的长度和变化会影响网络的延迟和丢包率。Playback底座必须反映这种队列动力学，因为它是网络行为的重要组成部分。

## 底座优势

- **真实性**：基于真实网络数据，具有高度的真实性
- **完整性**：覆盖多种网络场景和特性
- **稳定性**：长期运行，数据稳定可靠
- **可扩展性**：支持扩展到更多地域和场景

## 对上层设计的影响

Playback底座的设计约束对织虚的上层设计产生了重要影响：

- **切片策略**：必须基于100ms级的数据进行切片
- **聚类算法**：必须能够处理包含微观抖动和突发劣化的数据
- **拼接算法**：必须能够平滑连接不同的数据片段，同时保留原始数据的特性
- **验证指标**：必须包含对微观抖动、突发劣化、队列动力学的验证

## 结论

Playback底座是织虚的核心基础，其设计约束确保了生成的网络轨迹具有高度的真实性和可信度。严格遵守这些约束是织虚能够实现"合成链路 ≡ 物理链路"目标的关键。
